# ELV Auditor & CAD Estimator

Автоматизированный сервис аудита слаботочных инженерных систем (СКУД, СОТ, Wi-Fi, Акустика) и формирования коммерческих предложений из чертежей AutoCAD (.dwg, .dxf).

---

## Архитектура пайплайна

1. **Прием чертежа (/api/v1/dxf/audit-excel):**
   - Прямая поддержка бинарных .dwg и текстовых .dxf.
   - Если файл .dwg: запуск изолированного CLI-процесса ODAFileConverter (с обязательным фильтром *.DWG) -> генерация промежуточного DXF.
2. **Геометрический аудит (GeometryParser / ezdxf):**
   - Динамический маппинг слоев (алиасы для стен, камер, Wi-Fi, СКУД).
   - Детекция контуров помещений, центроидов и расчет площадей.
   - Трассировка дистанций до серверной стойки (Rack 0,0).
3. **Расчет систем:**
   - **СКУД:** расчет замков (280 кг), доводчиков, СМК, считывателей Mifare, кнопок выхода.
   - **СОТ:** расчет IP-камер по слоям и зонам.
   - **Wi-Fi:** расчет покрытия AP Wi-Fi 6 и емкости клиентов по площади.
   - **Аудио (100V):** расчет мощности потолочных громкоговорителей и подбор усилителей.
   - **Кабельная инфраструктура:** UTP Cat 5e, гофротруба d=20, клипсы.
4. **Финансовый сметный калькулятор (generate_bom_excel):**
   - Прайс-лист на оборудование и единичные расценки монтажа.
   - Генерация расчетных формул Excel (Сумма = Кол-во * Цена).
   - Автоматический расчет ПНР (10% от монтажа) и расходных материалов (3% от оборудования).
   - Итоговая сумма по смете.

---

## Требования к окружению

- macOS / Linux
- Python 3.11+
- ODA File Converter (установлен в /Applications/ODAFileConverter.app или доступен в PATH)
- Зависимости: fastapi, uvicorn, ezdxf, openpyxl, pydantic

---

## Быстрый запуск

```bash
# Активация виртуального окружения
source .venv/bin/activate

# Запуск сервера
uvicorn app.main:app --host 127.0.0.1 --port 8085 --reload
```

## Примеры вызова API

### Генерация коммерческого предложения из DWG

```bash
curl -X POST "http://127.0.0.1:8085/api/v1/dxf/audit-excel"   -F "project_name=БЦ Аврора"   -F "client_name=ООО Сибест"   -F "layer_walls=WALLS,АР_СТЕНЫ,СТЕНЫ"   -F "layer_cameras=CAMERAS_CCTV,СОТ,CCTV"   -F "layer_wifi=WIFI_AP,WI-FI"   -F "layer_doors=DOORS_ACS,СКУД"   -F "file=@plan.dwg"   -o "Коммерческое_предложение.xlsx"
```
